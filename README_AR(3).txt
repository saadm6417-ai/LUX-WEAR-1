LUX WEAR — ملفات مرشحة للاختبار قبل النشر

الملفات:
index.html — الصفحة الرئيسية
care-guide.html — تعليمات الغسيل والعناية
business-hours.html — مواعيد العمل
policy.html — سياسة الاستبدال والاسترجاع والضمان
customer-review.html — نموذج تقييم العملاء
admin.html — لوحة تحكم المدير
supabase-config.js — إعدادات الاتصال العامة بـ Supabase

طريقة الرفع:
ارفع الملفات السبعة وملف الإعدادات إلى جذر مستودع GitHub نفسه، مع الإبقاء على background.jpg وأي صور/ملفات تصميم مستخدمة حاليًا في أماكنها. لا ترفع README بدلًا من ملفات الموقع.

ملاحظات مهمة:
1) ملف supabase-config.js يحتوي عنوان المشروع ومفتاح Publishable عام فقط. لا تضع أبدًا Secret أو service_role key في GitHub.
2) لوحة التحكم تفصل النص العربي عن الإنجليزي؛ تعديل أحدهما لا يغير الآخر.
3) سجلا homepage وpolicy يجب نشرهما من لوحة التحكم حتى تظهر تعديلاتهما للزوار. لا تنشر محتوى تجريبيًا قبل مراجعته.
4) care-guide يقرأ الأكواد النشطة من care_guides. البيانات الاحتياطية القديمة لا تستخدم عند نجاح استعلام قاعدة البيانات وعدم وجود كود مطابق.
5) customer-review يحفظ التقييمات بحالة pending، ويحتاج المدير لاعتمادها من لوحة التحكم.
6) راجع روابط الصفحة الرئيسية من لوحة التحكم قبل النشر.

حالة الاختبار:
- فحص صياغة JavaScript المضمنة في الصفحات الستة: ناجح.
- لم يتوفر اتصال حي من بيئة العمل لاختبار Supabase Auth أو الكتابة/القراءة الفعلية؛ لذلك هذه نسخة مرشحة للاختبار وليست إثباتًا على نجاح تسجيل الدخول أو الحفظ الحي.
- لا تستبدل موقعك الحالي قبل إجراء اختبار المتصفح بعد الرفع التجريبي، واحتفظ بنسخة من الملفات الحالية للرجوع إليها.
